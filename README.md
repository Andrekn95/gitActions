Configurar correo: git config user.email "tu_correo@ejemplo.com"
Configurar nombre: git config user.name "Tu Nombre"
Iniciar Git local: git init
Vincular a GitHub por primera vez: git remote add origin https://github.com/USUARIO/REPO.git
Ver qué repositorio está vinculado: git remote -v
Ver el estado de tus archivos: git status
Preparar TODOS los archivos: git add .
Crear el commit Guardar la foto : git commit -m "mensaje descriptivo de lo que hiciste"
Renombrar la rama principal a main: git branch -M main
Subir por primera vez conectando las ramas: git push -u origin main
Subidas siguientes: git push
Traer y fusionar cambios desde GitHub: git pull origin main
